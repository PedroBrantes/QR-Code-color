# QR-Code-color

- Website Page Generator **QR Code**
- Export
    - PNG
- Personalize **QR code** with your favorite colors
    - Gradient
---

## Dependencies

- [QRCode.js](https://github.com/davidshimjs/qrcodejs): Library for generating QR codes.

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/PedroBrantes/QR-Code-color.git
   ```
2. Navigate to the project directory:
   ```bash
   cd QR-Code-color
   ```
3. Open the `index.html` file in a web browser.

## Usage

1. Enter the desired text in the input field.
2. Click the **Generate QR Code** button to create the code.
3. To export the QR code as a PNG image, click the **Export PNG** button.
4. To change the colors of the QR code, enter between 2 and 3 colors and click the **Change Color** button.
